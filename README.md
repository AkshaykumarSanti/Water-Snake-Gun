# 🐍💧🔫 Snake Water Gun Game

A fun and interactive **Snake Water Gun** game built using **Python** and **Streamlit** 🎮  
Challenge the computer, test your luck & strategy, and enjoy a colorful real-time gaming experience 🚀

---

# 🎯 Project Overview

This project is a simple yet interactive web application where users can play the classic **Snake–Water–Gun** game against the computer.

Built with **Streamlit**, the app provides a clean UI, instant result feedback, and engaging gameplay with celebration animations 🎉

---

# ✨ Features

✅ Player name input  
🐍 Choose between Snake / Water / Gun  
🤖 Computer generates random choices  
⚡ Instant result display (Win / Lose / Draw)  
🔄 Reset game functionality  
🎉 Celebration animation on victory  
🖥️ Interactive and beginner-friendly UI  

---

# 🛠️ Tech Stack

- 🐍 Python
- 🌐 Streamlit
- 🎲 Random Module

---

# 🎮 Game Rules

| Player Choice | Computer Choice | Result |
|---|---|---|
| 🐍 Snake | 💧 Water | 🐍 Snake Wins |
| 💧 Water | 🔫 Gun | 💧 Water Wins |
| 🔫 Gun | 🐍 Snake | 🔫 Gun Wins |
| Same Choice | Same Choice | 🤝 Draw |

# 🚀 Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/AkshaykumarSanti/snake-water-gun.git
cd snake-water-gun
```

---

## 2️⃣ Install Dependencies

```bash
pip install streamlit
```

---

## 3️⃣ Run the Application

```bash
streamlit run main.py
```
